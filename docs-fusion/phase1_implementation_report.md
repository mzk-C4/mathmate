### 设计模式

1. **单一职责原则**: 每个类只负责一个功能领域
2. **依赖注入**: 服务通过构造函数注入配置
3. **状态管理**: 使用 StatefulWidget 管理页面状态
4. **错误处理**: 统一的 Result 类型处理成功/失败
5. **模板方法**: Prompt 模板使用字符串模板模式
