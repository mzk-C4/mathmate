# MathMate v2.4.4 更新日志

## 新增功能

### 错题本系统 (Wrong Book)
- 全新错题本模块，支持记录、分类和复习错题
- 错题数据持久化存储，支持按知识点和错误类型分类
- 错题本页面集成到主应用导航

### GeoGebra 离线命令解析
- 新增离线几何命令解析器，无需联网即可解析常见 GeoGebra 命令
- 命令搜索服务支持本地索引快速检索
- 新增 commands_index.json 资产文件覆盖常用几何指令
- GeoChat 会话状态本地存储与恢复

### 考试系统后端增强
- 新增独立认证模块 (auth.py)，支持 JWT Token 签发与校验
- 考试路由增加认证中间件保护
- 题目选择器新增单元测试覆盖
- 数据库模型扩展支持更多考试元数据

### PDF 文本解析服务
- 新增 PDF 文本提取解析器，支持学习资料库的 PDF 内容索引

### 运维脚本
- 新增题目流水线脚本：题库导入、审核、Schema 校验
- 新增考试 E2E 冒烟测试脚本

## 优化与改进

### 更新服务安全加固
- APK 下载地址强制 HTTPS 且白名单校验（仅限 mathmate.top 域名）
- 支持 APK 文件 SHA256 完整性校验
- 下载文件大小限制（1MB ~ 350MB）
- 支持强制更新策略
- 下载进度实时回调与断点续传保护

### GeoGebra 交互优化
- GeoGebra 聊天页面重构，会话管理更稳定
- 移动端桥接层优化，渲染性能提升
- Agent Prompt 精简与优化

### 学习资料库
- 资料分类服务增强
- 入库服务支持更多格式

## 测试

- 新增 GeoChat 会话存储测试

- 新增命令搜索服务测试
